# Cold Contact System

## Project Overview
This project was originally created as a tool for sending cold emails. Over time, its concept evolved into something broader. It is now designed to serve as a centralized hub for managing cold outreach and prospect data.

The goal of the platform is to keep all information related to cold contacts in one place. This includes records of sent cold emails, companies scraped from the internet, notes from cold phone calls, and — in the future — contacts acquired through advertising campaigns on social media platforms.

By consolidating these different outreach channels into a single system, the project aims to simplify lead tracking, improve organization, and support a more structured outbound workflow.
